## 2. get_notice

**Expected JSON input schema**

```json
{
  "additionalProperties": false,
  "description": "Full details of one recall notice.",
  "properties": {
    "recall_number": {
      "description": "Recall number in the form F-NNNN-YYYY, e.g. F-0001-2025",
      "pattern": "^F-\\d{4}-\\d{4}$",
      "title": "Recall Number",
      "type": "string"
    }
  },
  "required": [
    "recall_number"
  ],
  "title": "GetNoticeInput",
  "type": "object"
}
```

**Rejected JSON input** (Part 2B)

```json
{
  "recall_number": "ABC-12"
}
```

**Returned error output**

```json
{
  "ok": false,
  "data": null,
  "error": "recall_number: String should match pattern '^F-\\d{4}-\\d{4}$'"
}
```

**Why it was rejected**

`recall_number` must match the pattern `^F-\d{4}-\d{4}$` (F, four digits, a four-digit year, e.g. F-0001-2025). `ABC-12` does not start with `F-` and has neither digit group, so it cannot be a recall number. Rejecting it here tells the caller the expected format instead of answering "not found" after a lookup.
